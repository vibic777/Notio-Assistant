# План: синхронизация Notio через Яндекс Диск

Состояние: **план, кода нет** (2026-10-05; Android D313). Облачные сервисы на паузе (правило 10 корневого `AGENT.md`);
работа начинается только после того, как владелец снимет паузу и выполнит раздел 2. Прежняя попытка и её выводы —
`android/docs/CLOUD_INTEGRATION_RU.md`; её код — коммит `187ae2f` (вход через Yandex LoginSDK, Диск REST v1).

Сведения о сервисе Яндекса записаны по памяти о его правилах и API; всё, что помечено «проверить», сверяется с действующей
документацией на этапе 0, до кода.

## 1. Что получится

- В Настройки → Синхронизация появляется «Яндекс Диск»: «Войти», «Синхронизировать», «Выйти», строка состояния.
- Данные лежат в папке приложения на Диске владельца: `Приложения/Notio`. Notio видит только эту папку
  (доступ `cloud_api:disk.app_folder`), остальной Диск ему недоступен.
- Всё, что уходит на Диск, зашифровано на устройстве паролем синхронизации (тот же формат, что у защищённой резервной копии
  `.json.zip.enc`). Яндекс хранит файлы, прочитать их не может. Без пароля данные с Диска не восстановить.
- Синхронизация идёт по нажатию кнопки, как сейчас между двумя устройствами. Фоновой работы нет (правило 2).

## 2. Что нужно от владельца до начала

1. **Снять паузу** с облачных сервисов (правило 10) — одной фразой.
2. **Учётная запись Яндекса**, от имени которой регистрируется приложение.
3. **Регистрация приложения** на `oauth.yandex.ru` (делается один раз, вместе, по шагам этапа 0):
   - название «Notio by vibic», значок;
   - платформа Android: пакет `com.notebudget.app` и отпечаток SHA-256 ключа подписи;
   - платформа для компьютера: адрес возврата (см. раздел 5);
   - доступ: только `cloud_api:disk.app_folder` («Доступ к папке приложения на Диске»).
   Итог регистрации — **ClientID**, он вписывается в сборку.
4. **Решить вопрос ключа подписи** (`docs/TODO_RU.md`, раздел 2): отпечаток ключа входит в регистрацию. Сейчас release APK
   подписан отладочным ключом этой машины; если ключ сменится позже, отпечаток в регистрации придётся заменить, иначе вход
   на телефоне перестанет работать.
5. **Телефон** для проверки входа на этапе 0.

## 3. Как устроена синхронизация (общее с планом Google)

Сервера у Notio нет, поэтому облако работает как общий почтовый ящик, а объединяет данные само устройство — тем же кодом,
что уже объединяет данные при синхронизации по сети и при импорте копии (`ImportPlanner`, режим «слияние»: новее побеждает).

- У каждого устройства свой файл-снимок: `Приложения/Notio/devices/<id устройства>.notio.enc`.
- «Синхронизировать»: (1) скачать снимки других устройств, которые изменились с прошлого раза; (2) слить их с данными
  устройства; (3) выгрузить свой новый снимок.
- Вложения (фото, видео, аудио, рисунки) в снимок не входят: они лежат отдельными зашифрованными файлами
  `Приложения/Notio/media/<id>` и выгружаются или скачиваются только те, которых на другой стороне нет.
- Два устройства могут синхронизироваться в разное время: каждое пишет только свой файл, конфликтов записи нет.

**Проверить до кода:** как слияние переносит удаление заметки с одного устройства на другое (корзина, окончательное удаление);
без этого удалённая заметка будет возвращаться с другого устройства.

## 4. Android

- Вход: официальный Yandex LoginSDK (`com.yandex.android:authsdk`), ClientID в манифесте. Токен хранится запечатанным
  ключом Android Keystore, как остальные секреты приложения.
- Диск: REST API v1 (`cloud-api.yandex.net/v1/disk/resources`), заголовок `Authorization: OAuth <токен>`, пути вида `app:/…`.
  Выгрузка в два шага: запросить адрес выгрузки, отправить файл; скачивание так же.
- Цена: прежняя попытка добавила к APK около 2,7 МБ на оба облака вместе; разрешение INTERNET уже есть (синхронизация по сети).
- Без WorkManager и без расписания: только кнопка.

## 5. Windows и Linux

- Вход: в браузере открывается страница Яндекса, после согласия Notio получает код и меняет его на токен
  (OAuth, код подтверждения с PKCE — без секрета приложения в программе).
  **Проверить:** какой адрес возврата разрешает Яндекс настольной программе — локальный `http://127.0.0.1:<порт>`
  или страница `oauth.yandex.ru/verification_code`, с которой человек переписывает код в Notio.
- Linux без монитора: вход по коду устройства (на экране другого устройства вводится короткий код). **Проверить**, что
  Яндекс выдаёт таким способом доступ к папке приложения.
- Токен хранится под DPAPI (Windows) и в Secret Service (Linux; сейчас на Linux секреты не защищены системой — это отдельный
  пункт `docs/TODO_RU.md`, раздел 1а, и он должен быть сделан раньше).
- Работа с Диском — тот же REST API; код общий с Android насколько позволяет `shared/src`.

## 6. Этапы

| Этап | Что делается | Чем заканчивается |
| --- | --- | --- |
| 0 | Регистрация приложения; на телефоне проверяется только вход и запись одного тестового файла | Вход работает на телефоне владельца. Без этого дальше не идём — урок D223 |
| 1 | Android: вход, выход, «Проверить связь», облачная копия вручную (выгрузить, показать список, восстановить) | Копия с телефона восстанавливается на том же телефоне |
| 2 | Android: синхронизация по разделу 3 — снимки устройств, слияние, вложения по одному | Два телефона сходятся к одним данным |
| 3 | Windows: вход через браузер и та же синхронизация | Телефон и компьютер сходятся |
| 4 | Linux, в том числе без монитора | Узел Linux сходится с остальными |

Каждый этап — своё решение в журнале, своя версия, все формы поставки, проверка на устройстве.

## 7. Риски и открытые вопросы

- **Регистрация.** Без неё вход невозможен, обойти кодом нельзя (D223).
- **Ключ подписи.** Смена ключа ломает вход на Android, пока не обновлён отпечаток в регистрации.
- **Пароль синхронизации.** Потерян — данные на Диске не прочитать. Нужен ясный текст в приложении.
- **Срок жизни токена и его обновление** — проверить на этапе 0.
- **Ограничения Диска** на размер файла и скорость выгрузки — проверить на этапе 0 на копии с видео.
- **Объём.** Первая синхронизация с большим количеством видео долгая; нужен показ хода и продолжение после обрыва.
- **Решить:** пароль синхронизации — отдельный или тот же, что у резервной копии.
- **Решить:** Яндекс и Google одновременно или по одному облаку на устройство.
