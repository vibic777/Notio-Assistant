Android — `android/docs/TODO_IDEAS_RU.md` (дела и идеи приложения), Windows — `windows/AGENT.md` §5 и §6.1 (паритет с Android).

Отметки: `[ ]` не сделано, `[x]` сделано, `(?)` нужно решение владельца.
