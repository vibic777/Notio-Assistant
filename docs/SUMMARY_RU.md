## 2026-10-11, ночь — падение Linux `.bin` при запуске: Windows и Linux 0.9.55

- **Отчёт владельца:** у друга `.bin` упал до окна: `SIGSEGV` в `getenv`, перед этим предупреждения JVM о кэше AOT
  («Saved blob's name … is different», «Failed to link AdapterHandlerEntry»).
- **Что найдено** (Windows D137): с кэшем быстрого запуска JVM сама включает хранение машинного кода (переходников) в
  кэше. Те же предупреждения собранное приложение печатает и в WSL на машине сборки — кэш находит переходники под
  чужой подписью; здесь это проходило, на другом компьютере закончилось падением.
- **Сделано:** машинный код в кэше выключен при записи, создании и чтении кэша (Windows и Linux); классы остались.
- **Проверено в WSL:** предупреждений нет, записей машинного кода не загружается, приложение стартует.
- **Не доказано:** файл отчёта `hs_err_pid….log` не видели, падение здесь не воспроизводится — причина наиболее
  вероятная, не подтверждённая. Если 0.9.55 упадёт так же, нужен этот файл. Запуск совсем без кэша:
  `JAVA_TOOL_OPTIONS=-XX:AOTMode=off ./Notio-….bin`.

- Иконка: стопка заметок, надпись «Notio by vibic» и карандаш, который её дописывает; иконка Windows рисуется из файла Android (`windows/tools/MakeIcon.java`).
- Заметки показываются карточками, компактным списком или сеткой (D300). Пять иконок внизу слева: три вида, сортировка, штампы времени. Те же виды и штампы — в меню «⋮» рядом с сортировкой.
- У каждой кнопки-иконки есть подсказка на языке приложения (D301): на телефоне — по удержанию, на компьютере — под мышью и под удержанным пальцем.
- **Правило значков и подсказок (D307, Windows D85):** каждая кнопка с надписью рисуется значком по смыслу, надпись всплывает подсказкой (Android — удержание пальца; Windows — курсор на значке или удержание пальца). Сделано общим механизмом, а не правкой каждой кнопки: кнопка сама узнаёт свою надпись и подбирает значок по общему для обеих платформ правилу `shared/src/com/notio/common/ButtonIcons.kt`. На Android значок получили 125 из 133 надписей на кнопках; оставшиеся 8 — кнопки, показывающие значение (единица, валюта, «не задано»). Словами остались также меню, чипы, вкладки, переключатели и надписи с подставленными значениями.
- **Режим экономии батареи и раздел «Батарея», как в FitEasy (D308, Windows D86).** Настройки → Общие → Батарея. Выключатель «Режим экономии батареи»: напоминания и слияния бюджета ставятся будильником, который система может объединять с другими (могут опоздать на несколько минут), мелодия обслуживается раз в секунду, декоративные анимации выключены. Ниже — что разрешает телефон: точные напоминания, фоновая работа, системная оптимизация батареи, с кнопками в настройки телефона и «Проверить снова». Приложение само никаких исключений из экономии не запрашивает. В Windows — выключатель в «Общих»: часы напоминаний проверяются раз в пять минут вместо минуты.
- Иконки при создании заметки и папки (D298).
- Бюджет: сумма, цель и остаток — каждый на своей строке, на карточке и в строках самого бюджета (D302).
- Глаз на карточке бюджета со скрытыми суммами (D306): показывает цифры только этой карточки, повторное нажатие скрывает.
- Журнал приложения сохраняется в файл JSON, TXT или LOG, как в FitEasy (D303). Код экспорта — первый файл в `shared/src`, общий для обеих платформ.
- В просмотре заметки MD под каждым пунктом списка тонкая линия (D305).
- Установщик Windows на десяти языках (Windows D80): язык Windows, если он из десяти, иначе английский; EXE несёт внутри тот же MSI.

**Подготовка к Linux и к переносу на другую машину** (Windows D87)

- Linux-версия — тот же код, что Windows. В сборку добавлены задачи для четырёх вариантов: один запускаемый файл `.bin`, AppImage, переносимый `tar.gz` и `.deb`; на Windows они пропускаются.
- На этой машине нет WSL, поэтому под Linux ничего не собрано и не запущено. Что на Linux будет работать иначе (секреты, запись камеры и экрана, автозапуск) — `docs/LINUX_RU.md`.
- Для переноса: `tools/make_transfer.sh` упаковывает историю, личные заметки и по просьбе ключ подписи; `docs/MOVE_RU.md` — что поставить и как проверить.

### Что не проверено

- Режим экономии: проверено, что выключатель сохраняется и будильники ставятся; что система действительно реже будит телефон и насколько опаздывают напоминания — не измерено.
- Значки на кнопках подобраны правилом по ключу надписи; как они выглядят на каждом экране, глазами просмотрены только два экрана Windows.
- Ничего из этого не установлено и не открыто руками: ни APK на телефоне, ни установщики Windows.
- Плавность окна глазами: проверено только то, что способ отрисовки сменился.
- Enter в списке на клавиатуре телефона: причина найдена чтением правила, на устройстве не воспроизведена.
- Напоминание и рисунок на телефоне: ошибки найдены чтением кода и закрыты тестами, но не воспроизведены на устройстве.
- Выбор языка установщиком на Windows с другим языком системы.
- Переводы новых строк и текстов установщика на 10 языков сделаны без вычитки носителями.
- Новый CI-job для Windows на GitHub ни разу не запускался.

### Выводы

- Главный риск был не в переносе кода, а в незакоммиченной сборочной обвязке и в истории с чужим авторством — оба закрыты.
- Автотесты ловят логику, но не поведение устройства: три из четырёх сегодняшних ошибок (напоминание, первый шаг, подёргивание окна) в тестах не видны. Без проверки руками их нельзя считать закрытыми.
- Нестабильный тест оказался настоящей ошибкой: изменение бюджета на Windows жило на области экрана и могло потеряться при выходе.
