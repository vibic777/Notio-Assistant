# Общие исходники Android и Windows

Помещать сюда только Kotlin-файлы, которые без изменений компилируются и корректно работают в Android `:app` и Windows `:desktopApp`. Каталог подключается к обоим клиентам напрямую по образцу FitEasy.

Пока переносимость не проверена, Windows JVM-исходники остаются в `windows/shared` и Android-зависимые исходники — в `android/app`. Не переносить файл сюда только потому, что он написан на Kotlin или Compose.

## Что здесь есть

| Файл | Что это |
| --- | --- |
| `src/com/notio/common/AppLogExport.kt` | Журнал приложения в файл JSON / TXT / LOG (Android D303) |
| `src/com/notio/common/ButtonIcons.kt` | Какой значок стоит за надписью кнопки: правило по ключу текста (Android D307) |
| `src/com/notio/common/HelpMap.kt` | Устройство справки: категории (вкладки), разделы (подвкладки), значки каждого раздела и правило «кнопка → раздел» для нажатой подсказки (Android D332) |
