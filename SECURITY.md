# Security policy / Политика безопасности

**English.** Notio keeps all data on the device and has no server. If you find a vulnerability (for example a way to read notes
past the app lock, to make a backup file execute or overwrite files, or to make the app send data somewhere), please **do not open a
public issue**. Use GitHub's private "Report a vulnerability" (Security tab of the repository) or write to the owner through the
contact on the profile page. Please include the app version, the Android version and the steps. This is a hobby project:
reports are answered as time allows, and a fixed version is announced in the release notes.

**Русский.** Notio хранит все данные на устройстве, сервера у него нет. Если вы нашли уязвимость (например, способ прочитать заметки
в обход блокировки, заставить файл резервной копии перезаписать файлы или заставить приложение куда-то отправить данные),
пожалуйста, **не создавайте публичное обращение**. Воспользуйтесь закрытой формой GitHub «Report a vulnerability» (вкладка Security
репозитория) или напишите владельцу по контакту в профиле. Укажите версию приложения, версию Android и шаги. Это любительский проект:
отвечаем по мере возможности, исправленная версия объявляется в описании релиза.

Supported version / Поддерживается: the latest release only / только последний релиз.
