## Что сделаем вместе перед первым релизом

- [ ] **Релизный ключ:** создать вместе (`keytool`), положить вне репозитория, заполнить `keystore.properties`, проверить подпись

  обновлять приложение. Сборка с новым ключом **не встанет поверх** отладочных: данные переносятся экспортом и импортом.

## Публикация (я выполняю, когда вы скажете «да»)

1. Резервная копия папки проекта; проверка `git status` и `git grep` на ключи ещё раз.
2. Пересоздание истории (по вашему выбору выше) и проверка автора коммитов.
3. `gh repo create <имя> --public --source . --push` (после вашего `gh auth login`); описание, темы (topics): `android`, `kotlin`,
   `jetpack-compose`, `notes`, `budget`, `offline`, `privacy`.
4. Проверка, что на GitHub нет ключей и лишних файлов (`private/`, `dist/`, `local.properties`), запуск Actions.
5. Релиз: тег `v1.0.0-beta1`, подписанный релизным ключом APK и SHA-256 в описании.
6. Включить в репозитории: Private vulnerability reporting, Issues, (по желанию) Discussions.
