# Contributing / Участие

**English.** Bug reports, checks on real phones, translation fixes and pull requests are welcome.

* Run `./gradlew :app:testDebugUnitTest` before a pull request; a new user-visible string must exist in all ten languages
  (see `translations/README.md`; a test enforces it).
* Notio is licensed under the [MIT License](LICENSE). By submitting a contribution you agree that it is released under the same licence.
* Do not include keys, passwords or personal data in issues or pull requests.

**Русский.** Сообщения об ошибках, проверки на настоящих телефонах, правки переводов и pull request'ы приветствуются.

* Перед pull request запустите `./gradlew :app:testDebugUnitTest`; каждая новая строка интерфейса должна быть на всех десяти языках
  (см. `translations/README.md`; это проверяет тест).
* Notio распространяется по [лицензии MIT](LICENSE). Отправляя свой вклад, вы соглашаетесь, что он выпускается на тех же условиях.
* Не выкладывайте в обращения и pull request'ы ключи, пароли и личные данные.
