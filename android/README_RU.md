# Notio by vibic

[English](README.md) · **Русский**

Notio — автономная записная книжка для Android: папки с заметками десяти видов — текст, списки с ценами, бюджеты, рисунки, чертежи,
аудио, фото, видео с камеры, запись экрана и расписание дня. Всё хранится **только на телефоне**: без аккаунта, без облака,
без аналитики, без рекламы.

> **Статус: бета (0.9.x).** Приложение функционально полное и покрыто примерно 760 автоматическими тестами, но большая часть
> проверена тестами, а не многими людьми на многих телефонах (особенно камера, запись экрана, наложения и будильник на экране
> блокировки). Делайте резервную копию (Настройки → Резервная копия) всего, что вам дорого. Сообщения об ошибках очень ценны.

## Возможности

| Вид заметки | Что умеет |
| --- | --- |
| **Текст** | Markdown с панелью форматирования; сначала «Просмотр», потом «Правка»; галочки нажимаются |
| **Список** | Статьи с количеством, единицей и комментарием; итоги по единицам; режим цен с итогами стоимости; перетаскивание; кнопки **«Изменить»** у количества и цены (+, −, =) |
| **Бюджет** | Дерево групп и статей: сумма, цель, остаток считаются сами; количество у статьи; **одна валюта** на бюджет; кнопка **«Изменить»** (+, −, =); **журнал операций** с сохранением в TXT / PDF |
| **Рисунок** | Растровый лист: карандаш, кисть, ластик, заливка, любой цвет, масштаб до 800 % |
| **Чертёж** | Векторные фигуры на слоях (скрыть, закрепить, порядок), заливка, масштаб |
| **Аудио** | Много записей в одной заметке, у каждой название и комментарий |
| **Фото / Запись камеры / Запись экрана** | Много записей в заметке, просмотр на весь экран, необязательные наложения (дата и время, место, текст, логотип) на новые снимки и видео |
| **Расписание** | Времена с описаниями и вычислители: сколько времени между двумя событиями |

Везде: папки с цветами и стилями, теги, поиск, закрепление, сортировка по двенадцати признакам (своя у каждой папки), перетаскивание,
штампы времени (по желанию), корзина со сроком хранения (в том числе для отдельных фото, видео и записей), напоминания (отложить,
повторять, экран-будильник поверх экрана блокировки), блокировка приложения (PIN-код, пароль, графический ключ 3×3, логин, биометрия),
необязательное шифрование базы данных на диске,
экспорт одной заметки (MD, TXT, PDF, JSON, PNG/JPEG, M4A, MP4, ZIP), полная резервная копия с необязательным паролем, светлая / тёмная
тема и десять цветовых тем, размер шрифта, свои фоны и **десять языков**: English, Русский, Беларуская, Français, Deutsch, Español,
Italiano, 中文, 日本語, 한국어 (переводы сделал ИИ, носители языка их ещё не вычитывали).

Описание по видам заметок — [docs/NOTE_TYPES_RU.md](docs/NOTE_TYPES_RU.md); полное описание возможностей —
[docs/FUNCTIONALITY_RU.md](docs/FUNCTIONALITY_RU.md).

## Приватность и безопасность

* **Данные остаются на устройстве.** Заметки лежат в закрытой памяти приложения. `allowBackup` выключен, поэтому Android не копирует
  их и в облако. Нашего сервера нет.
* **Сеть — только по вашему желанию и только для двух вещей:** если вы настроили восстановление блокировки по e-mail, приложение
  отправит одноразовый код через **ваш собственный** SMTP-сервер (STARTTLS или SSL/TLS с проверкой сертификата **и имени сервера**);
  и **синхронизация между вашими устройствами** в одной сети Wi-Fi (Настройки → Синхронизация) — напрямую, зашифрованно
  (AES-256-GCM, ключи ECDH), только пока открыта эта страница и только с устройствами, соединёнными кодом. Ни интернет-сервисов, ни облака.
* **Разрешения** запрашиваются в момент использования: микрофон (аудио, звук записи экрана), камера (фото / видео), местоположение
  (только если включить штамп места), уведомления и точные будильники (напоминания), полноэкранные уведомления (экран-будильник),
  «поверх других окон» (необязательная плавающая кнопка «Стоп» записи экрана), биометрия (разблокировка), интернет (необязательное
  письмо восстановления и синхронизация в локальной сети).
* **Блокировка:** PIN, пароли и ключи хранятся только как соленые хэши PBKDF2-HMAC-SHA256 (210 000 итераций); пауза после неверных
  попыток настраивается и растёт до 15 минут, есть необязательный общий лимит попыток, после которого либо доступно только
  восстановление, либо (по явному подтверждению) приложение стирает свои данные; пока блокировка включена, скриншоты и миниатюра
  в списке недавних заблокированы. Сама блокировка не пускает посторонних в приложение, но не шифрует базу данных на диске
  (а графический ключ 3×3 — небольшое пространство секретов) — для этого есть отдельная настройка ниже.
* **Шифрование базы данных (по желанию, выключено по умолчанию):** Настройки → Данные → «Шифрование базы данных» конвертирует
  файл базы на месте через SQLCipher (AES-256); пароль создаёт само приложение (не вводите его сами), он показывается один раз
  за кнопкой «Показать»/«Копировать» и хранится за замком Android Keystore. Это защищает именно файл базы от того, кто читает
  память телефона напрямую; медиафайлы (фото, видео, аудио, рисунки), на которые база ссылается, это (пока) не шифрует. Рядом
  с обычной резервной копией есть отдельный экспорт/импорт сырого файла базы — для переноса именно зашифрованного файла.
* **Резервные копии** можно защитить паролем: AES-256-GCM, ключ из пароля через PBKDF2-HMAC-SHA256 (600 000 итераций). Забытый пароль
  копии восстановить нельзя. В копии нет секретов блокировки и пароля почты.
* Подробности и обзор безопасности — [docs/SECURITY_REVIEW.md](docs/SECURITY_REVIEW.md) (на английском). О найденной уязвимости —
  см. [SECURITY.md](SECURITY.md).

## Установка

Нужен Android 9 (API 28) или новее (собрано для Android 16, компилируется с SDK Android 17).

1. Скачайте последний `Notio-by-vibic-<версия>.apk` на странице **Releases**.
2. Разрешите установку из источника, откуда открыли файл (Android спросит).
3. Откройте APK. Обновления ставятся поверх прежней версии, если APK подписан тем же ключом.

## Сборка из исходников

Приложение — папка `android/` репозитория Notio, собирается из корня репозитория. Нужны **JDK 21 или 25** и Android SDK (платформа 37, build-tools).

```bash
git clone <этот репозиторий>
cd <папка>
# создайте local.properties с путём к SDK, например:  sdk.dir=/путь/к/Android/Sdk
./gradlew :app:assembleDebug        # android/app/build/outputs/apk/debug/Notio-by-vibic-<версия>-debug.apk
./gradlew :app:testDebugUnitTest    # автоматические тесты (JVM + Robolectric), около 2 минут
```

Релизная сборка подписывается, только если файл `keystore.properties` (в репозиторий не попадает) указывает на ваш ключ:

```properties
storeFile=/путь/к/your.jks
storePassword=...
keyAlias=...
keyPassword=...
```

затем `./gradlew :app:assembleRelease`. **Не коммитьте** ключи и пароли.

Эмулятор для тестов не нужен: интерфейсные тесты идут на JVM через Robolectric.

## Как устроен код

Kotlin, Jetpack Compose (Material 3), Room (схема выгружается в `app/schemas`, у каждой версии есть проверенная миграция), DataStore,
kotlinx.serialization, CameraX, Media3 Transformer, ручное внедрение зависимостей (`AppContainer`).

```
app/src/main/java/com/notebudget/app/
  core/      база данных, настройки, будильники и уведомления, безопасность (хэши, TOTP, Keystore), почта, элементы интерфейса, тема
  domain/    модели, интерфейсы репозиториев, сценарии использования
  data/      репозитории Room, резервные копии / импорт / экспорт, файловые хранилища
  feature/   по пакету на экран или вид заметки (home, budget, notes/list, drawing, audio, media, settings, ...)
translations/  десять языков; ru/fr/de правятся в res/values-*, остальные создаются из translations/src/*.tsv
docs/          описание возможностей, журнал решений, чек-листы
```

Новый вид заметки — это один класс `NoteTypeDefinition` и одна строка в `AppContainer.noteTypes`. Резервные копии и файлы экспорта
терпимы к версиям: у каждого поля есть значение по умолчанию, неизвестные поля игнорируются, неизвестные виды заметок сохраняются, так
что файлы старых и новых версий продолжают открываться.

## Участие

Сообщения об ошибках и pull request'ы приветствуются, особенно: проверки на настоящих телефонах (какая модель, какой Android, что
случилось), правки переводов от носителей языка и отзывы о доступности (TalkBack). Перед pull request запустите
`./gradlew :app:testDebugUnitTest`. Каждая новая строка интерфейса должна быть на всех десяти языках (это проверяет тест; см.
`translations/README.md`). См. [CONTRIBUTING.md](CONTRIBUTING.md): вклад выпускается на тех же условиях (MIT).
